## Requirements

- Show Playback
  - The UI should show which show, if any, is loaded
  - It should have a playback progress bar
  - It should have controls to play, pause, and stop the loaded show.
  - Shows may also be looping.
- Triggers
  - Shows can also be triggered. Triggering causes the active show to stop, be replaced with a new show, and automatically start playing.
  - Shows are configured to allow to be overwritten by triggered shows.
  - Triggers can be:
    - Clock time (e.g. 10:00 PM)
    - WebSocket
      - The whole Aion Show System connects to a single websocket server.
      - There should be a config file to specify the host and port. If the file or config properties are absent it doesn't connect.
    - Command line: The show system is already running and the command line passes a message to the system, which triggers the show. 
    - Other shows finishing: A show can indicate another show to trigger upon completion. This should be specified in the show file.
- Config file
  - DMX output
  - Websocket server
  - Clock triggers
- UI
  - Does not need to show DMX levels
  - Does not need to edit the DMX configuration
